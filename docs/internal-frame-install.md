# TimeLens Internal 本地构建与逐机配置

此版本保留默认中文、浅色、窗口边框、无OCR回放、手动开始和暂停取消。新任务默认累计48小时，可在未开始且未绑定归档前配置总小时数；旧任务已开始或结束后保留原目标；默认前台所在屏幕，全部屏幕仍需单独选择。

## 员工专用包

预置批次的安装包只需要员工完成首次系统权限、在首页填写姓名、点击“开始采集”。授权激活、续期和上传均自动处理，不需要员工修改上传设置。管理员打包前的私有配置和构建校验见 [Cloudflare签发说明](cloudflare-issuer.md)。公开CI通用诊断包不含真实批次预置，不能直接替代员工专用包。

## 安装

macOS用已审查的依赖运行`scripts/build-internal-macos.sh`。它只构建`.app`，不安装、不启动、不录屏、不上传、不授系统权限。构建产物位于`project/src-tauri/target/release/bundle/macos/`。未签名/未公证构建仍需按本机系统提示处理，脚本不关闭系统安全设置。

Windows 使用 NSIS 当前用户安装，默认简体中文。2026-10-20 已完成 Windows 10 单屏远程桌面的安装与短时试录；当前修复版结果见对应 PR。Windows 11、多屏和长期采集仍需验收。标准测试包从本仓库 Actions 的 TimeLens-windows 产物获取，核对 BUILD-INFO.json 和 SHA256SUMS；不要把上游个人版安装包当作此内部版。

新装等待手动开始，重启保持暂停，权限由系统交互授予。不要覆盖上游个人版的数据目录；此版使用`~/.timelens-internal`，标识`com.timelens.internal`。安装或更新时保留已有数据，不覆盖个人版或其他设备配置。

## OSS直传（本地7天授权）

新模式步骤、Mac工具和续签说明见 [离线授权与OSS直传](oss-offline-upload.md)。以下配置属于保留的接收服务中转模式；不要把OSS Endpoint直接填成接收服务地址。

## 接收服务上传配置

在管理员配置页填写国内接收服务器的HTTPS根地址、独立调研编号和设备编号，核实目的地后保存。编号1–64字符，以英文字母或数字开始，仅包含字母、数字、点、下划线和横线。不填写age公钥。

token从`TIMELENS_UPLOAD_TOKEN`环境变量或当前用户`~/.timelens-internal/upload-token`读取，至少32个非空白ASCII字符；不通过聊天、命令参数或源码传递真实token。macOS/Linux文件必须0600、目录0700且由当前用户拥有，拒绝符号链接。Windows需在文件安全设置中移除继承权限，只授予当前用户所需读写，安装管理员应核对ACL。

当前开发版上传默认开启，配置就绪后自动发送队列中的原始截图，无需确认。可单独停止，停止选择会持久保存；在途请求仍可能返回回执。采集仍需手动开始。Cloudflare自动激活、续期与配套管理端配置见 [云端签发说明](cloudflare-issuer.md)。安装包尚未包含此改动，不能据源码宣称已部署。

仅发送原始WebP和必要的设备/调研、时间、显示器、大小、哈希信息；不上传活动数据库。上传成功本身不立即删除本地数据；已明确绑定归档的任务按实际/批准结束较早者加30天清理。本机清理不代表云端已经清理。旧截图不自动加入新队列；已有旧age包/旧回执任务需人工核对，不自动转换、解密、上传或清理。

隐私过滤仅按最前面的应用名、标识、窗口标题和网址判断，并在截图前后及保存前重新核对前台状态。后台应用不阻止截图，露出的后台内容可能入镜，无像素打码；处理敏感内容时应暂停采集。真实双屏、混合DPI、权限撤回、断网恢复、TLS和OSS需用约定的测试数据逐项验收。

## 本地测试

`cargo test --manifest-path project/src-tauri/Cargo.toml --lib`运行Rust假数据测试；接收服务和跨语言合同测试见`upload-server/README.md`。测试目录使用临时生成的图片、独立数据库和内存OSS，不截图、不读取用户历史图、不使用真实OSS凭据。

## 交付包中的环境目标

服务端模板已保留交付包指定的北京 OSS 桶 `umall-video-record` 和内网端点；非阿里云内网环境使用北京公网端点。客户端示例地址 `https://upload.timelens.internal` 仅供管理员核对，尚未验证其实际部署和连通性。两个模板位于 `upload-server/deploy/`，不会自动修改当前用户配置或启用上传。

交付包只附占位的 AccessKey/token，未附可直接使用的完整凭据。若现有服务器运行对方原版服务，还需部署兼容本地新版的接收服务；本次没有执行任何线上改动。
